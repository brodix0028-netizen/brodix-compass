### The Problem
Day 5 Onboarding, Laptop NOT Issued. Should be Day 3 per IT_Equipment_Policy.
Employee stuck, no idea who to ask. HR BP no warning. IT gets incomplete ticket = Escalation.

### Solution - 3 Features

1. JOURNEY TRACKER
Knows Day 5, Friction YES, shows what should happen next

2. POLICY Q&A with Citation
Q: Where is my laptop?
A: Per IT_Equipment_Policy [IT_OPS_001] Expected Day 3, You are Day 5
Always cites source

3. AUTO-ROUTER
Routes to IT Support via HR BP with full context. Complete ticket first time.

### Who It's For
- Employee: One place to ask, see next
- HR BP: Early warning + clear handoff
- IT/HR Service Owners: Complete, correctly routed requests

### Tech
Streamlit Cloud + Python Friction Engine + Policy Mapping + Guardrails Employee-only
